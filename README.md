# CroCab Android aplikacije

Ovaj javni repozitorij služi isključivo za službena CroCab Android APK izdanja
tvrtke Mobilitas Magna j.d.o.o.

- **CroCab**: korisnička aplikacija za naručivanje vožnje.
- **CroCab Driver**: aplikacija za ovlaštene CroCab vozače.

## Aktualna izdanja

- **CroCab 1.4.0 build 10**:
  [preuzmi korisničku aplikaciju](https://github.com/magnamobilitas/crocab-downloads/releases/download/crocab-v1.4.0-build10/CroCab-1.4.0-build10.apk)
- **CroCab Driver 1.3.0 build 9**:
  [preuzmi aplikaciju za vozača](https://github.com/magnamobilitas/crocab-downloads/releases/download/driver-v1.3.0-build9/CroCab-Driver-1.3.0-build9.apk)

APK datoteke nalaze se u odjeljku
[Releases](https://github.com/magnamobilitas/crocab-downloads/releases).
Izvorni kod, konfiguracija sustava, ključevi i administratorski alati nisu javno
objavljeni.

Ovaj repozitorij ne sadrži aplikaciju za dispečera, administratorsko sučelje,
Supabase konfiguraciju ni izvorni kod javne web-stranice. Ti su dijelovi sustava
odvojeni u privatne CroCab repozitorije.
