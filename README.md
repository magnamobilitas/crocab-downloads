# CroCab Android aplikacije

Ovaj javni repozitorij služi isključivo za službena CroCab Android APK izdanja
tvrtke Mobilitas Magna j.d.o.o.

- **CroCab**: korisnička aplikacija za naručivanje vožnje.
- **CroCab Driver**: aplikacija za ovlaštene CroCab vozače.
- **CroCab Dispatch**: aplikacija za ovlaštene dispečere i administratore.

CroCab repozitorijima. Javno je dostupan samo potpisani Dispatcher APK.
