## Sigurna instalacija

1. APK preuzmite isključivo iz poveznica iznad ili iz odjeljka **Releases** ovog
   repozitorija.
2. Android može zatražiti privremeno dopuštenje **Instaliraj nepoznate
   aplikacije** za aplikaciju koja je preuzela APK.
3. Nakon instalacije ponovno isključite to dopuštenje.
4. Po želji usporedite SHA-256 kontrolni zbroj datoteke s vrijednošću ispod.
